Anteater Auto Services

Anteater Auto Service is a full-stack web application that allows users to seamlessly book automotive appointments, manage their profile, view appointment history, and more. Built for a clean user experience, it integrates essential business features for a modern auto service interface.

✨ Features
🔐 User Authentication – Sign up, log in, log out using Clerk

👤 Profile Dashboard – View and update contact information (phone, address)

📅 Book an Appointment – Choose service, date, and pre-set time slots

🔁 Manage Appointments – Reschedule or cancel upcoming bookings

✅ Recent Appointments – Quick view of the last two completed services

📚 Appointment History – Full history of confirmed and completed bookings

🌟 Testimonials – Leave and read customer reviews

📞 Contact Us – Submit questions or feedback through a form

📍 Google Maps API Integration – Shows business location interactively

🛠️ Our Services – Overview of available auto services

🧾 About Us – Company mission and background

📱 Responsive Design – Optimized for desktop, tablet, and mobile use

♿ Accessible UI – WAVE-checked for improved accessibility across all users

🛠️ Tech Stack
Frontend: React, Clerk (for auth), custom CSS

Backend: Node.js, Express, AWS

Database: MongoDB

API Integration: Google Maps JavaScript API
